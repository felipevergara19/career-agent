Cómo funciona Career Agent

Guía rápida para operar el sistema tú mismo o para cualquier persona que clone el repositorio.

01...
Perfil y Rúbrica

Edita perfil/perfil-maestro.md y preferencias.md con tus logros y filtros duros.

02...
Conecta tu IA

Agrega una GEMINI_API_KEY en la pestaña API Keys & IA (o usa agy en consola).

03...
Busca + GraphRAG

El motor raspa 7 fuentes, descarta no-remotas/US-only y puntúa usando tus logros en Neo4j.

04LISTO
Arrastra y Postula

Arrastra una oferta a CV Listo para ensamblar el PDF automáticamente, revisa y postula.

Qué hace cada pieza en Docker

PostgreSQL (Persistencia)

Guarda tus ofertas, desgloses de puntaje, estados y corridas en un volumen persistente. Al apagar Docker no se pierde nada.

Neo4j (GraphRAG)

Conecta (Logro)→(Skill)←(Oferta). La IA lo consulta antes de evaluar cada vacante para citar tus logros reales y detectar brechas.

Bind Mounts Locales

Tus archivos Markdown y CVs PDF viven directamente en tu carpeta del repo (ofertas/, cvs-generados/), 100% portables a Git y CI/CD.
