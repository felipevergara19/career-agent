# Preferencias de Búsqueda y Rúbrica de Evaluación de Ofertas

> **Plantilla de ejemplo.** Copia este archivo a `perfil/preferencias.md` (ignorado por Git) y ajusta tus filtros, metas salariales y rúbrica.

## 1. Condiciones No Negociables y Geografías Objetivo

1. **Modalidad 100% Remota:** Compatible con tu país de residencia / huso horario.
2. **Foco Técnico:** Tus áreas principales (ej. Cloud FinOps, DevSecOps, SecOps, Platform Engineering).
3. **Seniority Objetivo:** Años de experiencia y nivel (Junior / Mid / Senior IC).

## 2. Roles Objetivo (Keywords)

- `Cloud FinOps Engineer`
- `DevSecOps Engineer`
- `Cloud Security Engineer`

## 3. Metas de Compensación Económica

- **Meta Fase 1:** `$X,XXX – $X,XXX USD/mes`
- **Meta Fase 2:** `$X,XXX+ USD/mes`

## 4. Rúbrica de Puntuación (0–100)

| Criterio | Peso Máx. |
| :--- | :---: |
| 1. Alineación Técnica Core | 35 pts |
| 2. Modalidad Remota y Huso Horario | 20 pts |
| 3. Idioma y Comunicación | 15 pts |
| 4. Banda Salarial / Tipo de Empresa | 15 pts |
| 5. Calce de Seniority y Factibilidad | 15 pts |
